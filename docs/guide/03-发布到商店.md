# 指南 03：上传 GitHub，发布到 Chrome 应用商店

## 一、上传到 GitHub（我们一起做）

1. 打开 https://github.com/signup 注册账号（用学校邮箱或常用邮箱都可以）。用户名会出现在网址里，建议简短好记。
2. 登录后点右上角 **+** → **New repository**：
   - Repository name 填 `dueboard`
   - 选 **Public**（公开）
   - 下面的 README、.gitignore、License 都**不要勾**（我们已经有了）
   - 点 **Create repository**
3. 把你的 GitHub 用户名告诉我。我会：
   - 把网页和文案里的 GitHub 地址换成你的用户名（已完成：Yokiwa）
   - 把代码上传（push）到这个仓库
4. 在仓库页面点 **Settings → Pages**：
   - Source 选 **Deploy from a branch**
   - Branch 选 `main`，文件夹选 `/docs`，点 **Save**
   - 等 1–2 分钟，介绍页就会出现在 `https://你的用户名.github.io/dueboard/`，隐私政策在 `…/privacy.html`
5. 发布第一个版本：仓库页面右侧 **Releases → Create a new release**：
   - Tag 填 `v1.0.0`
   - 标题填 `DueBoard 1.0.0`
   - 说明可以直接复制 `CHANGELOG.md` 里 1.0.0 的内容
   - 把我发给你的 `dueboard-1.0.0-chrome.zip` 拖进附件区
   - 点 **Publish release**

## 二、注册 Chrome 应用商店开发者账号

1. 打开 https://chrome.google.com/webstore/devconsole ，用 Google 账号登录。
2. 同意开发者协议，支付一次性注册费 **5 美元**。
3. 按提示验证邮箱。账号信息里的“发布者名称”会公开显示，可以填你的名字或 `DueBoard`。

## 三、上传插件（先“不公开”内测）

1. 开发者后台点 **新增项** → 上传 `dueboard-1.0.0-chrome.zip`。
2. **商品详情** 页：按 `store/listing.zh.md` 填写名称、说明、类别、语言；上传 `store/screenshots/` 里的截图；图标会从 zip 里自动读取。
   - 想同时提供英文说明：在“语言”里添加 English，再用 `store/listing.en.md` 的内容填写。
3. **隐私权规范** 页：按文案文件里“隐私权规范”一节逐项填写，隐私政策网址填第一部分第 4 步得到的网址。
4. **分发** 页：可见性选 **不公开（Unlisted）**。这样只有拿到链接的人能安装，适合内测。
5. 点 **提交审核**。第一次审核通常要几天，有时更久；审核结果会发到你的邮箱。
6. 审核通过后，把商店链接发给内测同学。

## 四、正式公开

内测稳定后（见指南 04 的时间线）：

1. 开发者后台 → 分发 → 可见性改为 **公开（Public）** → 保存并提交。
2. 把 README 和介绍页里的“添加到 Chrome”按钮改成商店链接（告诉我链接，我来改）。

## 五、以后发新版本

1. 我改好代码后，会把 `package.json` 里的版本号加一（例如 1.0.1），并发给你新的 zip。
2. 开发者后台 → 该插件 → **软件包** → 上传新版本 → 提交审核。
3. 审核通过后，用户的浏览器会自动更新，不需要重新安装。
4. 在 GitHub 上同步建一个新的 Release。

## （可选）Microsoft Edge 商店

2. 上传同一个 zip，文案和截图同上。
