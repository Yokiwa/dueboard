# 指南 02：检查插件能否读取数据，并导出示例数据

这一步用来确认两件事：
1. 插件能不能借用你浏览器的登录状态，读到 Brightspace 和 Gradescope 的数据；
2. 两个平台返回的数据长什么样，我会把它变成自动测试用的“示例数据”。

## 步骤

1. 在同一个 Chrome 里，先登录 https://purdue.brightspace.com 和 https://www.gradescope.com。
2. 点工具栏上的 DueBoard 图标，再点 **打开诊断工具**。
3. 点 **1. 检查能否读取**：
   - 两行都是 ✅：太好了，直接进行第 4 步。
   - 有 ❌：把整个页面截图发给我（截图里如果有你的名字，可以先打码）。
4. 点 **2. 导出示例数据**，会下载一个 `dueboard-fixtures.json` 文件。
5. **发送前先检查**：用记事本或任意文本编辑器打开这个文件，搜索（Ctrl+F / ⌘+F）你的：
   - 名字（中文名、英文名）
   - 学号 / Purdue 用户名（career account）
   - 邮箱

   正常情况下这些都已经被替换成 `[REDACTED]` 或 `user@example.com`。如果还能搜到，手动改掉再发给我。
6. 把文件发给我。

## 这个文件里有什么？

- 你这学期的课程名称和课程编号
- 第一门课的作业列表、测验列表和课程资料目录
- 你的 Brightspace 日历事件
- Gradescope 的课程列表页和第一门课的作业页

这些数据只用来写测试，会保存在项目的 `tests/fixtures/real/` 文件夹里。如果项目代码公开，这些数据也会公开，所以第 5 步的检查很重要。
