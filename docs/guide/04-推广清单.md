# 指南 04：内测与推广清单

对应设计文档第 9 节的时间线。每一步做完就打个勾。

## 第 1 步 · 自己先用一周（11 月）
- [ ] 安装 1.0.0，开着用 7 天
- [ ] 每天对照 Brightspace 和 Gradescope 网页检查：有没有漏掉的作业？时间对不对？有没有重复？
- [ ] 发现问题就告诉我：课程名 + 作业名 + 你看到的 vs. 正确的。必要时用诊断工具导出示例数据

## 第 2 步 · 小范围内测（12 月初，期末前）
- [ ] 建一个反馈表单（Google 表单即可），问题建议：
  1. 你主要用哪些平台？
  2. 有没有漏掉 / 显示错的作业？是哪门课的哪项作业？
  3. 你最常用哪个视图？
  4. 你最希望加什么功能？
  5. 你会推荐给同学吗？（1–5 分）
- [ ] 把表单链接告诉我，我放进设置页的“反馈”入口
- [ ] Chrome 商店以“不公开”方式上架（指南 03 第三部分）
- [ ] 找 5–10 位同学，尽量覆盖不同专业（理工科、文科各几位）
- [ ] 私聊发链接，附一句话介绍 + 30 秒教程（装好后先登录 Brightspace 和 Gradescope，再打开新标签页点“开始同步”）
- [ ] 一周后回访：还在用吗？为什么？

## 第 3 步 · 准备上线（12 月寒假）
- [ ] 根据反馈修问题；做最多人想要的功能（预计是截止前提醒）
- [ ] 素材：
  - [ ] 30 秒演示视频或动图：打开新标签页 → 看到卡片 → 点“去提交”
  - [ ] 3 张截图（已经在 `store/screenshots/`，有新界面再重截）
  - [ ] 一段中文介绍 + 一段英文介绍（可以直接用商店文案）
- [ ] 确认介绍页 `https://你的用户名.github.io/dueboard/` 正常
- [ ] 查阅普渡 IT 的使用规定（Acceptable Use Policy）。需要的话我帮你写一封说明邮件发给 IT

## 第 4 步 · 正式上线（2027 年 1 月开学第一周）
- [ ] 商店改为“公开”
- [ ] 发布渠道（每个渠道配截图或动图，一句话说清楚“它解决什么问题”）：
  - [ ] 中国学生微信群、Purdue CSSA
  - [ ] 大课的 Discord / GroupMe 群（先确认群规允许分享工具）
  - [ ] Reddit r/Purdue（标题例：*I made a free extension that shows all your Brightspace + Gradescope deadlines in one new tab*）
- [ ] 发帖时说明：免费、开源、数据只在本地、不是学校官方产品

## 第 5 步 · 持续运营
- [ ] 每周看一次 Chrome 开发者后台的“用户数”和“评分”
- [ ] 每两周整理一次反馈，挑最重要的 1–2 件事做
- [ ] 每次发新版本，在 CHANGELOG 和 GitHub Releases 里写清楚改了什么
