# 指南 01：在 Chrome 里安装 DueBoard 测试版

插件还没上架商店，所以要用 Chrome 的“开发者模式”手动安装。整个过程大约 2 分钟。

## 第一次安装

1. 下载我发给你的 `dueboard-x.y.z-chrome.zip`。
2. 双击解压，得到一个文件夹，里面有 `manifest.json`。把这个文件夹放到一个不会被误删的位置（比如“文档”里新建一个 `DueBoard` 文件夹）。
3. 在 Chrome 地址栏输入 `chrome://extensions` 并回车。
4. 打开右上角的 **开发者模式** 开关。
5. 点左上角的 **加载已解压的扩展程序**，选择第 2 步里的文件夹（选包含 `manifest.json` 的那一层）。
6. 列表里出现 **DueBoard**，就安装成功了。
7. 点浏览器右上角的拼图图标，把 DueBoard 旁边的图钉点亮，工具栏上就会一直显示它的图标。

> 打开新标签页时，Chrome 可能会问“这是您想要的新标签页吗？”，请选 **保留**。

## 更新到新版本

1. 把新的 zip 解压，**覆盖**原来那个文件夹里的文件。
2. 打开 `chrome://extensions`，点 DueBoard 卡片上的刷新按钮（圆形箭头）。

## 常见问题

- **提示“清单文件缺失或不可读取”**：你选的文件夹层级不对，要选直接包含 `manifest.json` 的那一层。
- **Chrome 每次启动都提示“停用开发者模式扩展程序”**：这是测试版才会出现的正常提示，点关闭即可。上架商店后就没有了。
