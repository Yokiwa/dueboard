# Assignment Scores Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Show the score of finished work next to its Done / Submitted badge ("Done · 18/25"), read from the Brightspace gradebook, Gradescope, Pearson MyLab and, on Refresh, platform assignment pages.

**Architecture:**
- One `Score` type and one text reader (`findScore`) are shared by everything.
- Fetch-based connectors (Brightspace, Gradescope, Pearson) put `score` on their raw items.
- Platform pages are read by a new `score` visit mode, which reuses the existing visit runner and stores its result in `captured`.
- `buildDashboard` picks one score per finished item, and `DueBadge` shows it.

**Tech Stack:** WXT 0.21 (MV3), TypeScript, React 19, Vitest + happy-dom, Playwright e2e (`scripts/e2e-visits.cjs`).

**Spec:** `docs/superpowers/specs/2026-11-10-scores-design.md`

## Global Constraints

- The repository, UI, docs and commit messages are English only.
- No new permissions in `wxt.config.ts`.
- DueBoard never types, starts or submits anything. The Pearson score request is the same read-only callback the "see score" link sends.
- Scores stay in `browser.storage.local`. Nothing is uploaded.
- A score is shown only when the item is finished: `doneByUser || submitted`.
- A wrong number is worse than none. Ambiguous matches or reads give no score.
- **Pearson:** at most 10 score requests per sync, 2 at a time, 10-second timeout each. A failure never fails the Pearson sync.
- **Score visits:**
  - run only when due-date visits would run (the `settings.visits` gate and trigger);
  - are scheduled after due-date targets;
  - count toward `MAX_VISITS` (25) and the 5-minute budget;
  - never open a title matching `NEVER_OPEN`.
- **Score text format:**
  - `earned/possible` with no spaces, trailing `.0` dropped ("18.0 / 20.0" → "18/20", "1.5 / 25 points" → "1.5/25");
  - percentages as "92%";
  - letter grades as given ("A-").
- The release is version 1.3.0, with a CHANGELOG entry and Firefox lint at 0 errors.
- Every commit ends with:
  `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` and `Claude-Session: https://claude.ai/code/session_01YSmZu67Q1vHhbmVgwmotvG`.

## Review Focus

1. **Two items in one course share a normalized name with one gradebook grade** ("Homework 1" in two modules): neither gets the score. Test: Task 2.
2. **A platform page shows the student's score and a class average** ("Your score: 18 / 25 points", "Class average: 15 / 25 points"): no score, because there are two different labeled scores. Test: Task 1.
3. **A score visit fails** (sign-in page, timeout, window closed) **after an earlier visit found a score:** the stored score is kept. Test: Task 6.
4. **The Pearson session expires between the list fetch and a score request** (the callback returns a sign-in HTML page): that row gets no score, and the Pearson sync still returns `ok: true` with its items. Test: Task 4.
5. **The student unticks Done on an item that has a captured score:** the badge goes back to the due countdown with no score. Test: Task 5.

- [ ] **Step 1: Write failing tests** in `tests/core/scoreText.test.ts`:

  - Accepted, each as `findScore([line], 'WileyPLUS')?.text`:

    | Input line | Expected text |
    | --- | --- |
    | `'1.5 / 25 points'` | `'1.5/25'` |
    | `'18/20 pts'` | `'18/20'` |
    | `'Score: 18 / 20'` | `'18/20'` |

    | `'Score: 92%'` | `'92%'` |
    | `'Grade 87.5 %'` | `'87.5%'` |
    | `'18 of 20 points earned'` | `'18/20'` |

  - The result carries `earned`, `possible` and `from: 'WileyPLUS'`. `evidence` is the matched line, trimmed to at most 120 characters.
  - Rejected (return `null`):
    - `'3/10'`, `'Question 3 / 10'`, `'Page 2/5'`, `'10 questions'`;
    - `'Due 11/10/2026'`, `'11/10'`;
    - `'70% score reduction will be applied to work submitted after due date'`, `'50% score reduction after third attempt'`, `'Score: 10% late penalty'`;
    - `'30 / 20 points'` (earned more than possible × 1.5), `'5 / 0 points'`.
  - Two different labeled scores give `null`: `['Your score: 18 / 25 points', 'Class average: 15 / 25 points']`.
  - The same score repeated gives a score: `['18 / 25 points', 'Score: 18/25']` returns `'18/25'`.
  - The WileyPLUS header lines from the saved export, inlined as a synthetic array, return `'1.5/25'`: `['PHYS 172H - HW11 - FA26', '10 questions', '1.5 / 25 points', '1h 41m spent', 'Due Monday, Nov 9 at 11:59 PM (EST)', '70% score reduction will be applied to work submitted after due date']`.
